# Olist 电商经营诊断业务结论

记录日期：2026-09-23

本文件是最终看板对应的业务结论摘要。金额单位为 BRL，比例统一为百分比。

## 1. 经营总览

- 成交订单量：96,478 单
- GMV：15,422,605.23 BRL
- 客单价：159.86 BRL
- 复购客户率：3.00%
- 延迟率：8.11%
- 差评率：12.85%
- 平均履约天数：12.56 天

2017-11 GMV 达到 1,153,528.05 BRL，是观察期内的单月峰值；2018 年多数月份稳定在约 100 万 BRL，未再次突破该峰值。

## 2. 类目与地区

GMV 前五类目合计贡献约 39.26%，依次为：

- health_beauty：1,412,089.53 BRL，占 9.16%
- watches_gifts：1,264,333.12 BRL，占 8.20%
- bed_bath_table：1,225,209.26 BRL，占 7.95%
- sports_leisure：1,118,256.91 BRL，占 7.25%
- computers_accessories：1,032,723.77 BRL，占 6.70%

平台收入既依赖头部类目，也依赖少数头部卖家。经营监控不能只看总 GMV，还要同时观察头部卖家和头部类目的履约与评价。

## 3. 履约与评价

- 准时订单平均履约：10.88 天
- 延迟订单平均履约：31.52 天
- 延迟 4 至 7 天订单差评率：61.31%
- 延迟 8 天及以上订单差评率：78.51%

延迟与差评高度相关，但当前数据只能说明相关，不能直接证明因果。延迟主要同时出现在卖家处理和运输配送两个阶段，应优先核查高风险地区、卖家和承运环节。

## 4. 客户经营

- 复购客户：2,801 个
- 复购客户率：3.00%
- 复购客户 GMV 占比：5.60%
- 首购到二购平均间隔：80.8 天，中位数 28 天

高消费待激活客户占 8.09%，贡献 13.93% 的 GMV，是复购召回中优先测试的人群。Olist 是低复购市场，增长更依赖持续获取新客户和减少一次性客户流失。

## 5. 卖家风险

- 风险卖家：22 家
- 风险卖家 GMV：1,384,771.19 BRL

风险卖家不应直接淘汰。应先进行订单抽样、备货时效核查和物流路径诊断；整改无改善后，再进入限流或淘汰流程。

## 6. 数据限制

- 数据没有成本、利润、退款和浏览行为，不能计算利润或页面漏斗。
- 延迟与差评是观察性相关，不能直接解释为因果。
- 多类目订单会同时计入多个类目，类目 GMV 不能直接相加得到平台 GMV。
- 2016 年样本较少，2017-11 带有促销季节性。
