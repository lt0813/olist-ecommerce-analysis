# 数据说明

本项目使用 Olist 的巴西电商公开数据集，约 10 万订单、9 张表。

## 表

- customers
- geolocation
- sellers
- products
- orders
- order_items
- order_payments
- order_reviews
- product_category_translation

## 下载

- Kaggle: `olistbr/brazilian-ecommerce`
- 和鲸社区搜索 `Olist`

下载后请把 CSV 放在本目录下，再执行 `../sql/03_import_data.sql`。
本仓库不提交原始 CSV。
